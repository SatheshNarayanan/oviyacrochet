# Image Prompts for Custom Designs

Use these prompts to generate the missing preview images for the Custom Orders page using any image-generation tool (Midjourney, DALL-E, etc.). The images should be 4:5 portrait composition, saved as WebP format.

**Base Negative Prompt / Avoid List:**
`text, letters, watermark, brand logo, official artwork, human face, hands, blurry, plastic look, machine-knitted smooth fabric, melted or distorted stitches, extra or missing parts, asymmetrical eyes or ears, cartoon illustration, 3D render`
